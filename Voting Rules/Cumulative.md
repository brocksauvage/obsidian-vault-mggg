# Cumulative

**Cumulative voting** is a multi-winner rule in which each voter is given a number of votes (often equal to the number of seats) and may distribute them among candidates however they wish—including casting multiple votes ("plumping") for a single candidate.

## How it works
- Each voter receives *k* votes for *k* seats.
- Voters allocate those votes freely across candidates (all on one, spread evenly, etc.).
- The top vote-getters fill the seats.

## Key characteristics
- Lets minority or cohesive groups concentrate support to win representation (semi-proportional).
- Simple ballots but requires strategic vote allocation.
- Historically used in U.S. corporate board elections and some local jurisdictions (e.g., Illinois state legislature, 1870–1980).
