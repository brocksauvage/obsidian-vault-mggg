# Single Transferable Vote

**Single Transferable Vote (STV)** is a multi-winner, proportional rule using ranked ballots. Candidates need to reach a [[Droop Quota|quota]] of votes to be elected. Surplus votes from winners and votes from eliminated candidates transfer to voters' next preferences, so few votes are "wasted." It also goes by the name of proportional ranked choice voting.

## How it works
1. Voters rank candidates in order of preference.
2. A quota is set (commonly the [Droop quota](https://en.wikipedia.org/wiki/Droop_quota)).
3. Candidates reaching the quota are elected; their surplus transfers proportionally.
4. If seats remain, the lowest candidate is eliminated and ballots transfer.
5. Repeat until all seats are filled.

## Key characteristics
- Produces roughly proportional, multi-member representation.
- Generalizes single-winner [[Ranked Choice Voting]] to multiple seats.
- Tabulation is complex; surplus-transfer methods vary.
- Used in Ireland, Malta, and Australian Senate elections.
